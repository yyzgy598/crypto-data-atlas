## 1. 永续 DEX

### Hyperliquid（重点）
- 文档：https://hyperliquid.gitbook.io/hyperliquid-docs/for-developers/api ；Python SDK https://github.com/hyperliquid-dex/hyperliquid-python-sdk ；Rust SDK 同组织
- Base：REST `https://api.hyperliquid.xyz`（主网）、`https://api.hyperliquid-testnet.xyz`；WS `wss://api.hyperliquid.xyz/ws`；自建节点 `hl-node` 可本地暴露 `/info`（见下）。
- 所有 Info 请求都是 `POST /info`，JSON `{"type": ..., ...}`。限频：按 IP 1200 权重/分钟；多数 info 请求 weight 20，`l2Book`/`allMids`/`clearinghouseState`/`orderStatus`/`spotClearinghouseState`/`exchangeStatus` 为 2，`userRole` 为 60，Explorer 类 40；地址级额外限制（按累计成交量，每 1 USDC 成交 1 次请求配额 + 初始 10000）。超限返回 429。
- 市场元数据与行情
  - `{"type":"meta"}` 永续资产列表（szDecimals、maxLeverage、onlyIsolated、marginTableId）；`{"type":"metaAndAssetCtxs"}` 元数据 + 每个资产的 `funding`（当前小时费率）、`openInterest`（币）、`prevDayPx`、`dayNtlVlm`、`premium`、`oraclePx`、`markPx`、`midPx`、`impactPxs`、`dayBaseVlm`
  - `{"type":"spotMeta"}`、`{"type":"spotMetaAndAssetCtxs"}` 现货代币与交易对（`@index` 命名，如 `@107` = HYPE/USDC）
  - `{"type":"perpDexs"}` 列出 HIP-3 builder 部署的独立永续 DEX（`dex` 参数，`meta` 可传 `{"type":"meta","dex":"xyz"}`）
  - `{"type":"allMids"}`（可带 `dex`）
  - `{"type":"l2Book","coin":"BTC","nSigFigs":5,"mantissa":null}` 盘口（最多 20 档/边）
  - `{"type":"candleSnapshot","req":{"coin":"BTC","interval":"1m","startTime":<ms>,"endTime":<ms>}}` K 线，interval 1m/3m/5m/15m/30m/1h/2h/4h/8h/12h/1d/3d/1w/1M，最多返回 5000 根
  - `{"type":"recentTrades","coin":"BTC"}`（非官方 info 类型，部分节点支持）；成交主要靠 WS `trades`
  - `{"type":"fundingHistory","coin":"BTC","startTime":<ms>,"endTime":<ms>}` 历史资金费（每小时一条，含 `premium`），单次最多 500 条，按时间翻页
  - `{"type":"predictedFundings"}` 各资产 Hyperliquid/Binance/Bybit 预测资金费对比（**自带跨所对比**）
  - `{"type":"perpsAtOpenInterestCap"}` 触及 OI 上限的资产
  - `{"type":"maxMarketOrderNtls"}`、`{"type":"perpDeployAuctionStatus"}`、`{"type":"spotDeployState","user":...}`、`{"type":"tokenDetails","tokenId":"0x..."}`（现货代币供应、创世、部署者）、`{"type":"spotPairDeployAuctionStatus"}`
  - `{"type":"exchangeStatus"}`、`{"type":"marginTable","id":...}`、`{"type":"vaultSummaries"}`、`{"type":"vaultDetails","vaultAddress":...}`（HLP 等金库 APR、PnL 历史、follower）、`{"type":"leadingVaults","user":...}`
  - `{"type":"delegations","user":...}`、`{"type":"delegatorSummary"}`、`{"type":"delegatorHistory"}`、`{"type":"delegatorRewards"}`、`{"type":"validatorSummaries"}`（质押/验证者）
- 用户/地址级（用于巨鲸追踪、钱包采集）
  - `{"type":"clearinghouseState","user":"0x..."}`（可带 `dex`）：持仓（`assetPositions[].position` 含 szi、entryPx、liquidationPx、unrealizedPnl、leverage、marginUsed、cumFunding）、`marginSummary`、`crossMarginSummary`、`withdrawable`
  - `{"type":"spotClearinghouseState","user":...}` 现货余额
  - `{"type":"openOrders","user":...}`、`{"type":"frontendOpenOrders","user":...}`（含 trigger、tpsl、reduceOnly、isPositionTpsl、orderType、cloid 等前端字段）
  - `{"type":"userFills","user":...,"aggregateByTime":false}` 最近 2000 笔成交；`{"type":"userFillsByTime","user":...,"startTime":<ms>,"endTime":<ms>}` 按时间翻页（每次最多 2000，可回溯全历史）
  - `{"type":"historicalOrders","user":...}` 最近 **2000** 条订单事件（含 open→filled/canceled 多条记录，status 字段：open/filled/canceled/triggered/rejected/marginCanceled/liquidatedCanceled/reduceOnlyCanceled/...），**不能翻页、不能按时间过滤**
  - `{"type":"orderStatus","user":...,"oid":123}`（oid 或 cloid）单订单状态
  - `{"type":"userFunding","user":...,"startTime":...}`、`{"type":"userNonFundingLedgerUpdates","user":...,"startTime":...}`（充提、转账、清算、金库操作）、`{"type":"userRateLimit","user":...}`、`{"type":"userFees","user":...}`、`{"type":"userRole","user":...}`（user/vault/agent/subAccount）、`{"type":"subAccounts","user":...}`、`{"type":"portfolio","user":...}`（账户价值/PnL 曲线 day/week/month/allTime）、`{"type":"userTwapSliceFills"}`、`{"type":"userVaultEquities"}`、`{"type":"referral"}`、`{"type":"extraAgents"}`、`{"type":"userDexAbstraction"}`、`{"type":"frontendUserInfo"}`
  - 清算：无单独公共清算接口；清算以 `userFills` 中 `liquidation` 字段（含 `liquidatedUser`、`markPx`、`method`）体现，WS `trades`/`userFills` 可见；全市场清算需扫全链（节点 `replica_cmds`）或用第三方（Hypurrscan、Coinglass、HyperDash、Hyperscan、ASXN、Hypurr.co）
- WS 订阅 `{"method":"subscribe","subscription":{"type":...}}`：`allMids`（可带 dex）、`notification`、`webData2`（前端全量账户快照）、`candle`（coin, interval）、`l2Book`（coin, nSigFigs, mantissa）、`trades`（coin）、`orderUpdates`（user）、`userEvents`（user：fills、funding、liquidation、nonUserCancel）、`userFills`（user）、`userFundings`、`userNonFundingLedgerUpdates`、`activeAssetCtx`（coin：资金费、OI、oracle）、`activeAssetData`（user, coin）、`userTwapSliceFills`、`userTwapHistory`、`bbo`（coin）、`clearinghouseState`（user）、`openOrders`（user）。每 IP 最多 100 连接、1000 订阅、每分钟 2000 消息；需 `{"method":"ping"}` 心跳（60s 无消息断开）。可用 `post` 方法在 WS 上发 info/action 请求。
- 自建节点与全量数据：`hl-node` 可写出 `replica_cmds`（每个区块的全部订单/成交操作）、`node_trades`、`node_order_statuses`、`node_fills`、`periodic_abci_states`；官方 S3 归档 `s3://hl-mainnet-node-data/`（`explorer_blocks`、`node_fills_by_block`、`node_trades`、`replica_cmds`，lz4 压缩，requester-pays），这是获取**全量历史订单/清算**的唯一官方途径。另有 `https://api.hyperliquid.xyz/explorer`（txDetails、blockDetails、userDetails）与 Explorer WS `explorerBlock`、`explorerTxs`。
- 第三方 Hyperliquid 数据：Hypurrscan（`https://api.hypurrscan.io/` — 区块、交易、清算、HYPE 持仓/质押、Hyper EVM，有 swagger）、HyperDash（`https://hyperdash.info`，巨鲸持仓/清算，部分无公开 API）、ASXN Dashboards、Hyperscan / Purrsec（EVM 浏览器 Blockscout API `https://www.hyperscan.com/api`）、Hypurr.co、Hyperliquid Stats（`https://stats-data.hyperliquid.xyz/Mainnet/...` 社区统计 JSON：daily_usd_volume、open_interest、liquidations_by_coin、funding_rate 等）、Coinglass 的 Hyperliquid 专区（巨鲸持仓、清算地图、HLP）、DefiLlama（volume/fees/OI）、Dune 上的 Hyperliquid spellbook 表、Allium、Nansen Hyperliquid 面板、Artemis。
- HyperEVM：JSON-RPC `https://rpc.hyperliquid.xyz/evm`（chainId 999）、测试网 998；浏览器 Hyperscan/Purrsec；预编译合约可直接在 EVM 读 L1 状态（持仓、oracle）。
- 坑：`historicalOrders` 2000 条上限 + 事件日志语义（一个订单多条记录）；OI 单位是币；资金费率每小时结算（年化 = 小时费率 × 24 × 365，对比 8h 所要换算）；`candleSnapshot` 用 `t`/`T`（开/收时间）；地址级限频按成交量；HIP-3 的 builder DEX 需要显式传 `dex` 参数，默认接口只返回主 DEX；现货资产用 `@index` 而不是名字。

### dYdX v4（dYdX Chain）
- 文档：https://docs.dydx.xyz/ ；Indexer REST `https://indexer.dydx.trade/v4/`，WS `wss://indexer.dydx.trade/v4/ws`；节点 REST/gRPC 见 docs（`https://dydx-ops-rest.kingnodes.com` 等公共节点）。
- 市场：`GET /perpetualMarkets?limit=`（含 oraclePrice、openInterest、nextFundingRate、volume24H、trades24H、priceChange24H、initialMarginFraction）、`/orderbooks/perpetualMarket/{ticker}`、`/trades/perpetualMarket/{ticker}?limit=100&createdBeforeOrAtHeight=`、`/candles/perpetualMarkets/{ticker}?resolution=1MIN&fromISO=&toISO=&limit=1000`（resolution 1MIN/5MINS/15MINS/30MINS/1HOUR/4HOURS/1DAY）、`/historicalFunding/{ticker}?limit=100&effectiveBeforeOrAt=`、`/sparklines?timePeriod=ONE_DAY`、`/time`、`/height`、`/compliance/screen/{address}`。
- 地址：`GET /addresses/{address}`、`/addresses/{address}/subaccountNumber/{n}`、`/fills?address=&subaccountNumber=&market=&limit=100&createdBeforeOrAt=`、`/orders?address=&subaccountNumber=&status=OPEN|FILLED|CANCELED`、`/orders/{orderId}`、`/transfers`、`/historical-pnl?address=&subaccountNumber=`、`/perpetualPositions?address=&subaccountNumber=&status=OPEN`、`/assetPositions`、`/historicalBlockTradingRewards/{address}`、`/historicalTradingRewardAggregations/{address}?period=DAILY`、`/affiliates/...`、`/vault/v1/megavault/historicalPnl`、`/vault/v1/megavault/positions`、`/vault/v1/vaults/historicalPnl`。
- WS 频道：`v4_markets`、`v4_orderbook`（id=ticker）、`v4_trades`、`v4_candles`（id=ticker/resolution）、`v4_subaccounts`（id=address/subaccount）、`v4_parent_subaccounts`、`v4_block_height`。
- 坑：Indexer 成交是撮合后才有，链上 maker 订单在 memclob 不上链；清算在 `fills` 中 `type=LIQUIDATED`/`LIQUIDATION`，也可在 `/orders` 的 `orderFlags`；历史数据深度依赖 Indexer 运营方（dYdX Trading 官方 Indexer 保留全量）。dYdX v3（StarkEx，`api.dydx.exchange/v3`）2024 年底关闭。

### Aster（原 APX，BNB Chain/多链永续）
- 文档：https://github.com/asterdex/api-docs ；Base 永续 `https://fapi.asterdex.com`，现货 `https://sapi.asterdex.com`；WS `wss://fstream.asterdex.com`。**接口风格完全照搬 Binance fapi**：`GET /fapi/v1/exchangeInfo`、`/fapi/v1/depth`、`/fapi/v1/trades`、`/fapi/v1/aggTrades`、`/fapi/v1/klines`、`/fapi/v1/indexPriceKlines`、`/fapi/v1/markPriceKlines`、`/fapi/v1/premiumIndex`、`/fapi/v1/fundingRate`、`/fapi/v1/fundingInfo`、`/fapi/v1/ticker/24hr`、`/fapi/v1/openInterest`、`/fapi/v1/ticker/bookTicker`；WS 频道同 Binance（`@aggTrade`、`@markPrice`、`@kline_`、`@depth`、`@forceOrder`）。Pro 模式（链上签名）与 Simple 模式（1001x）两套。

### GMX（Arbitrum / Avalanche / Solana）
- 文档：https://docs.gmx.io/docs/api ；v2 REST：`https://arbitrum-api.gmxinfra.io` 与 `https://avalanche-api.gmxinfra.io`（备 `*-api.gmxinfra2.io`）：`GET /prices/tickers`（oracle 价格）、`/prices/candles?tokenSymbol=BTC&period=1m&limit=1000`、`/signed_prices/latest`、`/tokens`、`/markets`、`/markets/info`、`/apy`、`/incentives/...`、`/report/ui/...`；v2 子图（Goldsky/Synthetics stats）`https://subgraph.satsuma-prod.com/.../gmx-arbitrum-stats/api` 等；链上 `Reader` 合约 `getMarketInfo`、`getOpenInterest`、`getPosition` 需用 RPC；GMX 聚合统计用 `https://stats.gmx.io` 后端（GraphQL）。清算与仓位事件来自 `EventEmitter` 合约事件（`PositionIncrease`、`PositionDecrease`、`OrderExecuted`），用 Dune `gmx_arbitrum` 表或 Goldsky 子图最方便。

## 5. 口径与注意事项
- **DEX 成交量刷量**：永续 DEX 与小币 DEX 的量常被激励刷高（Aster、部分 Solana meme）。对比 DefiLlama（会标注 `doublecounted`）、Token Terminal、Artemis 三家。
- **价格来源**：DEX 价格受流动性深度影响，小池子价格不可当参考价；Dexscreener/GeckoTerminal/Birdeye 会按最大流动性池给价，但 `liquidity.usd < 10k` 的价格不要用。
- **链 ID 命名不统一**：Dexscreener 用 `ethereum`/`bsc`/`solana`，GeckoTerminal 用 `eth`/`bsc`/`solana`，Birdeye 用 `ethereum`/`bsc`/`solana`，Moralis 用 `0x1`/`0x38`/`mainnet`，Codex 用数字 chainId（Solana=1399811149）。
- **历史深度**：Dexscreener 无历史；GeckoTerminal 免费约 6 个月 K 线；Birdeye 历史随套餐；Codex/Bitquery/Dune 全历史。
- **Hyperliquid 清算与全量订单**只能用节点数据或 S3 归档；API 层只能看到用户级的 fills 和 2000 条订单。
- **永续 DEX 资金费率周期**：Hyperliquid 1h；dYdX 1h；GMX 连续计息；Lighter 1h（结算 8h 显示）；Aster 8h（部分 4h）；Paradex 8h 连续；Drift 1h；对比年化时统一。
