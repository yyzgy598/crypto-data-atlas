## 1. 区块浏览器 API

### Etherscan V2（统一多链）
- 文档：https://docs.etherscan.io/ ；V2 统一入口 `https://api.etherscan.io/v2/api?chainid={id}&module=&action=&apikey=`，一个 key 覆盖 60+ 链（Ethereum 1、BSC 56、Polygon 137、Arbitrum 42161、Optimism 10、Base 8453、Avalanche 43114、Linea 59144、Scroll 534352、zkSync 324、Blast 81457、Mantle 5000、opBNB 204、Gnosis 100、Celo 42220、Cronos 25、Fraxtal 252、Taiko 167000、Sonic 146、Berachain 80094、Unichain 130、Abstract 2741、ApeChain 33139、World 480、Monad、HyperEVM 999（2025 加入）、Sophon、Swellchain 等；`chainlist` 接口 `https://api.etherscan.io/v2/chainlist`）。旧的 bscscan.com/polygonscan.com/arbiscan.io 单链 API 2025 年起逐步只接受 V2。
- 认证：`apikey` 查询参数；免费 5 req/s、100k/天；付费 Standard/Advanced/Professional 提高到 10–30 req/s 并解锁 Pro 接口。
- 关键 module/action
  - `account`：`balance`、`balancemulti`、`txlist`（普通交易，`startblock`/`endblock`/`page`/`offset<=10000`/`sort`）、`txlistinternal`（内部交易，可按 `txhash`/区块范围）、`tokentx`（ERC-20 转账，可按 `contractaddress`+`address`）、`tokennfttx`（ERC-721）、`token1155tx`、`getminedblocks`、`txsBeaconWithdrawal`、`balancehistory`（Pro）、`tokenbalance`、`tokenbalancehistory`（Pro）、`addresstokenbalance`（Pro，地址全部代币）、`addresstokennftbalance`（Pro）、`addresstokennftinventory`（Pro）、`fundedby`（**首笔资金来源**，Pro/部分链）
  - `contract`：`getabi`、`getsourcecode`（源码、编译器、是否代理、Implementation）、`getcontractcreation?contractaddresses=`（创建者、创建交易、创建区块时间）、`verifysourcecode`、`checkverifystatus`
  - `transaction`：`getstatus`、`gettxreceiptstatus`
  - `block`：`getblockreward`、`getblockcountdown`、`getblocknobytime?timestamp=&closest=before`（**时间 → 区块高度**）、`dailyavgblocksize`（Pro）、`dailyblkcount`（Pro）、`dailyblockrewards`（Pro）、`dailyavgblocktime`（Pro）、`dailyuncleblkcount`（Pro）
  - `logs`：`getLogs?fromBlock=&toBlock=&address=&topic0=&topic0_1_opr=and&topic1=&page=&offset=1000`（事件日志，最多 1000 条/页）
  - `proxy`：以太坊 JSON-RPC 代理 `eth_blockNumber`、`eth_getBlockByNumber`、`eth_getTransactionByHash`、`eth_getTransactionReceipt`、`eth_call`、`eth_getCode`、`eth_getStorageAt`、`eth_gasPrice`、`eth_estimateGas`、`eth_getLogs`（部分链）
  - `token`：`tokensupply`、`tokensupplyhistory`（Pro）、`tokenholderlist`（Pro，**持币地址列表**）、`tokenholdercount`（Pro）、`tokeninfo`（Pro：名称、官网、社交、价格）、`addresstokenbalance`
  - `gastracker`：`gasestimate?gasprice=`、`gasoracle`（Safe/Propose/Fast GasPrice、suggestBaseFee、gasUsedRatio）、`dailyavggaslimit`（Pro）、`dailygasused`（Pro）、`dailyavggasprice`（Pro）
  - `stats`：`ethsupply`、`ethsupply2`（含质押与销毁）、`ethprice`、`chainsize`（Pro）、`nodecount`、`dailytxnfee`（Pro）、`dailynewaddress`（Pro）、`dailynetutilization`（Pro）、`dailyavghashrate`（Pro）、`dailytx`（Pro）、`dailyavgnetdifficulty`（Pro）、`ethdailymarketcap`（Pro）、`ethdailyprice`（Pro）、`tokensupply`
  - Name tags / Labels：无公开 API（Pro 用户可下载 `https://etherscan.io/exportData?type=...`；标签页面 `https://etherscan.io/labelcloud`，社区数据集 `brianleect/etherscan-labels` GitHub）
- 坑：`txlist` 单地址最多返回 10000 条（需按区块范围切分）；`getLogs` 1000 条/页；V2 对新链支持进度不一；Name tag 不开放。

## 4. 选型建议与坑
- **查一个地址的全部历史（EVM）**：Etherscan `txlist`+`tokentx`（免费，1 万条上限）→ Alchemy `getAssetTransfers`（分页无上限）→ Covalent `transactions_v3` / Moralis `wallets/{addr}/history`（带解析）→ 自建 Erigon/Reth + Otterscan `ots_searchTransactions`。
- **查某代币全部持有者**：Blockscout `tokens/{addr}/holders`（免费）、Etherscan `tokenholderlist`（Pro）、Covalent `token_holders_v2`（可指定历史区块）、Moralis `erc20/{addr}/owners`、Ankr `ankr_getTokenHolders`、Bitquery `TokenHolders(date)`、Dune `balances_*` 表；Solana 用 Helius `getTokenAccounts` / Solscan `token/holders` / Vybe。
- **按事件抓合约日志**：少量用 `eth_getLogs`（公共节点一般限 10k 块或 10k 条）；回填用 Envio HyperSync、cryo、Covalent `events/address`、Alchemy（范围大但限 2k 条）；长期用 Goldsky Mirror / QuickNode Streams / Subsquid。
- **时间 → 区块**：Etherscan `getblocknobytime`、Moralis `dateToBlock`、DefiLlama `https://coins.llama.fi/block/{chain}/{timestamp}`（免费多链）。
- **标签（Labels）**：Etherscan 不开放；可用 Dune `labels.*`/`cex.addresses`、Flipside `crosschain.core.dim_labels`、Arkham（见 05）、Nansen（见 05）、Moralis Entity、SolanaFM `tagged-accounts`、Vybe `known-accounts`、Hypurrscan `alias`、Blockchair 的 `is_known`、开源 `https://github.com/dawsbot/evm-labels`、`https://github.com/brianleect/etherscan-labels`、`https://github.com/MetaMask/contract-metadata`、Tron 的 Tronscan `addressTag`。
- **公共 RPC 不要用于生产**：限频、无 archive、随时下线。多活策略：Alchemy + QuickNode/dRPC 互备。
- **历史状态（archive）**：`eth_call` 带历史区块、`eth_getBalance` 历史余额需 archive 节点（Alchemy Growth+、QuickNode Archive、dRPC、Erigon 自建）。
- **BTC 地址余额历史**：mempool.space/Esplora 只给当前；历史用 Blockbook `balancehistory`、Blockchair（付费 premium）、BigQuery/Allium、自建 electrs。
